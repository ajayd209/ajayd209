## 💰 MicroInvest — Infrastructure Investment Platform<br>
A full-stack fintech-inspired investment platform built with **Python, Django, Django REST Framework, PostgreSQL, and JavaScript**. The platform is designed to manage infrastructure investment projects, investors, transactions, wallets, and administrative operations.<br><br>**Key Features:**<br><br>* 🔐 User authentication and role-based access control<br>* 👤 Investor and admin dashboards<br>* 🏗️ Infrastructure project management<br>* 💰 Investment management and tracking<br>* 💳 Digital wallet and transaction management<br>* 📒 Ledger-based transaction architecture<br>* 🔔 Notifications and investment updates<br>* 📊 Investment and project tracking<br>* 🛡️ Secure backend architecture and API-based design<br>* 🗄️ PostgreSQL database integration<br>* 🚀 Deployed on Render<br>
